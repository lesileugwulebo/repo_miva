Regulatory & Data Governance Mapping

Alignment with Nigerian Data Protection Act (NDPA 2023) and National Cloud Policy 2025.

Nigeria Data Protection Act (NDPA 2023)

  • Data Residency: Sensitive database tier strictly maintained in private subnets without public ingress.
  • Cross-Border Transfer: Inter-cloud data transport encrypted using FIPS-compliant AES-256 IPsec tunnels.
  • Accountability: Immutable audit logging via AWS CloudTrail and Azure Activity Logs.

National Cloud Policy 2025

  • Cloud-First Alignment: Native AWS Transit Gateway and Azure VPN Gateway integration.
  • Sovereignty & Security: Zero Trust micro-segmentation limiting cross-provider reachability.
  • Identity Control: Centralized workforce federation via Entra ID & AWS IAM Identity Center.
